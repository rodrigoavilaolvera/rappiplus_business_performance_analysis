# RappiPlus Business Performance Analysis

## Project Overview

This project analyzes RappiPlus business performance using a combination of **Excel, SQL, Python, and Power BI**.

The objective was to prepare, analyze, and transform business data into actionable insights and develop an interactive Power BI dashboard focused on key commercial and financial performance indicators.

## Tools & Technologies

* **Excel** — Initial data preparation and review
* **SQL** — Data querying and analysis
* **Python** — Data cleaning, transformation, analysis, and visualization
* **Power BI** — Data visualization, KPI analysis, and interactive dashboard development

## Analysis Process

### 1. Data Preparation — Excel

The initial dataset was reviewed and prepared in Excel to organize the information and ensure consistency before further analysis.

### 2. Data Analysis — SQL

SQL was used to query and analyze the dataset, applying filtering, aggregations, grouping, and other basic analytical operations to obtain relevant business metrics.

### 3. Data Processing & Analysis — Python

Python was used for data cleaning, transformation, exploratory analysis, KPI calculation, and visualization.

Libraries used included:

* pandas
* NumPy
* Matplotlib
* Seaborn

### 4. Business Intelligence — Power BI

The analyzed data was incorporated into Power BI to create an interactive business performance dashboard.

The dashboard includes:

* Revenue
* Profit
* Marketing performance
* Average Ticket
* Average Quantity
* Revenue YTD
* Product and category performance
* Sales trends
* Cost analysis
* Quantity sold
* Interactive filters
* Detailed drill-through analysis

## Dashboard

The Power BI dashboard provides an executive overview of business performance while allowing users to explore specific products, categories, dates, and performance indicators.

### Key Business Questions

The analysis was designed to help evaluate:

* How is overall revenue and profitability performing?
* Which products and categories contribute most to revenue?
* How do sales and profit change over time?
* What is the relationship between sales performance and marketing activity?
* Which products generate higher or lower business performance?
* How can KPIs be monitored through an interactive dashboard?
